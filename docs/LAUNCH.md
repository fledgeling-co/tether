# Deployment acceptance

The reusable kit builds and runs locally. Public deployment requires an approved host, a DNS suffix and control-plane TLS certificates. Follow `deploy/README.md`; keep the relay's host allowlist closed and publish only ports 80 and 443.

Before enabling a cloud route, verify certificate renewal, host registration, reconnect after host sleep, revocation, resource limits and logs without payloads or pairing codes. Then pair a physical iPhone over cellular and exercise the embedding app's permissions and recovery paths.

No public domain, certificate or cloud account was created by this implementation. The provisioned native Mac Keychain fixture passed eight phases and removed its six test accounts. Windows checks exercised CurrentUser storage, retained native rows and external accessibility names. Screen-sharing latency, cellular pairing, cross-user Windows storage and full screen-reader operation remain separate acceptance work.
